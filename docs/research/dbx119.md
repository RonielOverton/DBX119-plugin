# dbx 119 — research notes

What the plugin is modeled on, with the source for each fact. Items marked **unverified** need a manual or a real unit before calibration.

## What it is

- Stereo dB-linear compressor/expander from dbx, sold from 1976, based on the dbx 117. Stereo RCA in and out. ([audiocostruzioni](https://audiocostruzioni.com/en/prodotto/dbx-119/), [eBay listing](https://www.ebay.com/itm/117260216091))
- Marketed with the "Decilinear" name. One rotary control goes from compression through 1:1 to expansion. ([audiocostruzioni](https://audiocostruzioni.com/en/prodotto/dbx-119/))

## Controls

| Control | Behavior | Source |
|---|---|---|
| Compress/Expand (large knob) | Compression up to infinity:1 (119; the 117 stops at 1.4:1), expansion up to 1:2. At 1.0 the signal passes unchanged. | [tonbandmuseum](http://www.tonbandmuseum.info/dbx-dbx-117-119.html), [homerecording.com](https://homerecording.com/bbs/threads/how-to-connect-dbx-119.150093/) |
| THRESHOLD | Replaces the 117's LEVEL MATCH. Sets the level where gain is unity; wider range, marked every 10 dB. | [vintagedigital](https://vintagedigital.com.au/?p=166983) |
| MODE switch | LINEAR (whole range, like the 117) or ABOVE THRESHOLD (acts only above the threshold). Replaces the 117's Slow/Norm release switch. | [vintagedigital](https://vintagedigital.com.au/?p=166983), [tonbandmuseum](http://www.tonbandmuseum.info/dbx-dbx-117-119.html) |
| Red LED | Lights when the program level exceeds the threshold. | [vintagedigital](https://vintagedigital.com.au/?p=166983) |

Infinite compression is meaningful only in ABOVE THRESHOLD mode, where it works as a limiter. ([tonbandmuseum](http://www.tonbandmuseum.info/dbx-dbx-117-119.html))

## Timing and detection (117/119 family)

- Attack typically 12 ms; 100 µs on steep edges.
- Release follows the envelope at up to 180 dB/s; timing is program-dependent.
- RMS detection and VCAs are described for dbx expanders in general. **Unverified** for the 119 circuit itself.

Source: [tonbandmuseum](http://www.tonbandmuseum.info/dbx-dbx-117-119.html)

## Published specifications (117/119)

20 Hz–20 kHz ±0.5 dB; THD typically 0.1 %; input noise 90 dB below 1 V; max input 30 V; input impedance 50 kΩ. ([tonbandmuseum](http://www.tonbandmuseum.info/dbx-dbx-117-119.html))

## Conflicting or missing information

- Some sellers list the range as "1.4:1 compression to 2.0:1 expansion"; that is the 117 range. The 117/119 manual supplement and tonbandmuseum both state the 119 reaches infinity:1. The model follows the manual.
- Numeric threshold range: not found. The plugin uses -60 to 0 dBFS.
- Stereo linking: the 117 manual mentions preserving the stereo image in expansion, which suggests linked detection. **Unverified.** The plugin links by default and has a switch.
- The original manual ([manualzz](https://manualzz.com/doc/6659264/instruction-manual---dbx-the-legend-of-the-sound)) could not be fetched from here. Reading it is the first calibration task.

## How the model maps this

See `src/dsp/CompanderCore.h`:

- Gain (dB) = (slope − 1) × (level − threshold). LINEAR uses the full range; ABOVE THRESHOLD uses only the part above the threshold.
- Detector: one-pole mean-square integrator (12 ms), then the dB level may not fall faster than 180 dB/s.
- Safety limits (not from the hardware): +24 dB max boost, −60 dB max cut, detector floor −80 dBFS.
- Not modeled yet: the 100 µs fast attack on steep edges, VCA coloration, noise.

## Name and trademark

"dbx" is a trademark of Harman. The plugin ships as **RTO 119 Compander** and describes itself as inspired by a 1970s compressor/expander. Check with a lawyer before using "dbx" in any product name or marketing.
