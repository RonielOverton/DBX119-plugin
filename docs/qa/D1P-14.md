2. **Linear mode LED never lights.** Set MODE to Linear. Keep THRESHOLD at -20 dB and play the same loud material. Expect the LED to stay off for the whole run. Try THRESHOLD at -60 dB and at 0 dB, and check the LED stays off. Result: Not run.
3. **Wide stereo or out-of-phase source compresses less when linked.** Load a stereo synth pad with wide stereo (or invert one channel of a stereo pair). Set AMOUNT to -0.5, THRESHOLD -20 dB, MODE Linear. Play it with STEREO LINK on, note the gain meter, then turn LINK off and note it again. Expect linked compression to be less than unlinked for this material. Result: Not run.
4. **Heavy kick and bass no longer over-trigger.** Play a mix or loop with a heavy kick and sub bass in mono-ish stereo, with AMOUNT -0.5, THRESHOLD -20 dB, MODE Linear, LINK on. Compare the gain meter with the previous version (build `main` for A/B). Expect less compression on the kick and sub than before. Result: Not run.
5. **Sample rates (recommended).** Set the session to 44.1 kHz and to 96 kHz. Repeat steps 1 and 3. Expect the same LED and compression behavior at each rate. Result: Not run.
6. **Mono track (recommended).** Put the plugin on a mono track (1 channel). Expect normal compression, LED behavior as in step 1, and no change when LINK is on or off. Result: Not run.
7. **Bypass round trip (recommended).** Play material, bypass the plugin for a few seconds, then un-bypass. Listen for any click or gain jump at the un-bypass point. Result: Not run.
