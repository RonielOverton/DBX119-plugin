## Manual steps for the owner

Load `build/RTO119_artefacts/Release/VST3/RTO 119 Compander.vst3` (or the Standalone app) after `cmake --build build --config Release`. Use a session at 48 kHz unless a step says otherwise. Set AMOUNT to the centre position (0), OUTPUT to 0 dB, STEREO LINK on, MODE Linear. With AMOUNT at 0 the gain is unity, so the detector does not change what you hear. Only the input filter is active.

1. **Sub-bass sweep (row 22).** Make a sine sweep from 40 Hz down to 5 Hz over about 20 s, at about -12 dBFS, on a stereo track. Play it through the plugin, or bounce it and open the file. Expect a gradual fall in level below about 10 Hz: about -0.5 dB at 20 Hz, about -1.8 dB at 10 Hz, about -5 dB at 5 Hz. There should be no sudden drop, no ringing, and no click. Result: Not run.
2. **Program material (row 23).** Play a full mix or a drum loop through the plugin with the plugin active, then with it bypassed (A/B). Expect no audible change at normal listening level. The only change is a small loss below about 20 Hz. Result: Not run.
3. **DC offset (row 24).** Put a DC offset on a track (for example, a constant offset from a utility plugin placed before RTO 119). Play it through the plugin and check the output. Expect the offset to be gone within about 0.2 s, since the filter time constant is about 22 ms. Result: Not run.
4. **Measurement (row 21, when D1P-15 is ready).** Compare the owner's recorded response at unity with the predicted first-order curve: -3.01 dB at 7.23 Hz, -0.09 dB at 50 Hz, about -0.005 dB at 1 kHz. Each measured point must sit within 0.5 dB of the prediction. Result: Not run (waiting for owner measurement).
